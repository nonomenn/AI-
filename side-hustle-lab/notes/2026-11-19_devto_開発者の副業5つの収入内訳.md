# 開発者が5つの副業を試し、SaaSは月$800〜1,200・AI APIアフィリは月$350〜600と主張

- 反応: 不明
- 評価: 済 / 別角度: 済(ideas/不動産動画自動編集ツールの月額提供.md)

## 主張(本人が言っていること)
- フリーランス開発: 時給$100〜150、年間約$48K
- 自作SaaS: 月$800〜1,200の定期収入。開発に約6か月、今は週5時間程度の保守(時給換算約$50)
- 技術ブログ広告: 月$200〜400。月4〜8本、1本2〜4時間(約$16/時)
- YouTubeスポンサー: 1本$500〜1,500、制作約15時間、案件は不安定
- AI APIアフィリエイト: 月$350〜600。初期設定約10時間、今は月2時間程度(約$158/時)。直近3か月の登録数は23・18・31件

## 中身(手法)
1. 5つの副業を並べ、時給換算で比較
2. 結論は「定期収入が入るアフィリエイトが最も受動的に近い」
3. 記事末尾で特定のAI APIサービスの紹介リンクへ誘導

## 評価
| 軸 | 判定 | 理由 |
|---|---|---|
| 証拠の強さ | C | 全部本人の申告。第三者の確認なし。経費の記載なし |
| 宣伝度 | 高 | 誘導先: AI APIサービスのアフィリエイト登録。結論がそのまま紹介リンクに向かう構造 |
| 初期費用 | 手法による | アフィリは0円、SaaSは開発時間(約6か月) |
| 必要時間 | SaaS: 開発数か月→週5時間保守 | |
| 再現性 | 低〜中 | アフィリは自分のチャンネル(約2年運営)の集客が前提。SaaSは「作る」までは相性が良い |
| 天井 | SaaS 月数万円〜(推測) | 定期課金なので積み上げ型 |
| リスク | 中 | 売上の数字は総額で手残りは不明。アフィリ先サービスの継続性に依存 |
| オーナーとの相性 | 中〜高 | SaaS(小さな専用ツールの月額提供)は既存ツール資産と相性が良い |

## 手残りの試算(推測)
- SaaS 月$1,000(約15万円、1ドル150円と仮定)− 決済手数料・サーバ代(合計1〜2割と推測)= 約12〜13万円 / 週5時間 → 時給約$50(本人計算)。ただし開発6か月分の時間は含まれない

## 結論
**見送り**(アフィリ部分) / **参考**(SaaS部分) — アフィリは紹介報酬が主で、宣伝構造の記事。SaaS(定期課金の小さなツール)という型だけ別角度の材料にする。

## 別角度のヒント(/angles の材料)
- 既存の動画自動編集ツールを、不動産会社・撮影者向けに月額で提供する(工程の自動化を売る)
- 週5時間の保守で回る、という運用の軽さは、オーナーの時間条件に合う
