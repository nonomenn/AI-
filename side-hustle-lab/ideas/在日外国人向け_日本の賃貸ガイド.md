# 在日・移住予定の外国人向け「日本の賃貸の借り方」英語ガイド

- 元になった情報: notes/2026-11-19_xpurojekuto_海外版500円note.md
- 型: 同じ手法を別の市場へ(日本の当たり前を海外向けに説明し直す)

## 一言で
敷金・礼金・保証会社・初期費用の内訳・内見の見方など、日本の賃貸の「当たり前」を英語の短いガイドにして、1本500〜1,000円で販売する。

## なぜ勝てそうか
- 元の手法の「日本の当たり前を海外向けに」に、オーナーの不動産の知識がそのまま使える
- 外国人の部屋探しは、言葉と慣習の壁が大きい(推測。需要は販売前に確かめる)
- 将来、外国人向け物件紹介(英語テロップのルームツアー)や仲介の紹介につなげられる

## 競合の確認(2026-11-27)
- 「外国人が日本で部屋を借りる方法」は、送金サービスや外国人向けメディアが詳しく無料で公開している。有料は電子書籍$8.99、購入ガイド$20(Gumroad)など。売上は非公開
- → 全体像のガイドは無料記事と比べられる。やるなら「退去時の原状回復費」「更新料」「重要事項説明書の読み方」など狭い悩みに絞る
- 根拠: notes/2026-11-27_web_外国人向け日本の賃貸ガイドの競合.md

## 評価
| 軸 | 判定 | 理由 |
|---|---|---|
| 初期費用 | ほぼ0円 | Gumroad 等は無料で出品できる |
| 必要時間 | 1本2〜3時間(推測) | 原稿をAIで英語化し、内容は自分で確認 |
| 最初の1円まで | 2〜6週間 | 集客の場所(Reddit の日本移住系コミュニティ等)次第 |
| 天井 | 月数万円(推測) | 単価が低い。本命は物件紹介・仲介への導線 |
| リスク | 低 | 法律・契約の説明は一般論にとどめ、断定しない。宅建業に当たる行為(仲介)はしない |
| オーナーとの相性 | 中〜高 | 不動産の知識あり。英語の確認は要協力者 |

## 最小の検証(2週間)
- ガイドを2本作る(例: 初期費用の内訳、保証会社とは)
- 販売ページを1つ作り、集客先を1か所決めて紹介する(規約を確認してから)
- 見る数字: 販売ページの閲覧数、購入数

## 判定
**保留** — 単体の収益は小さい。先に「制作代行」を検証し、余力があれば着手。
