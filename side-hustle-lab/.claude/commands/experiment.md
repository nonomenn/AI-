---
description: アイデアを2週間で試す計画を作る(予算上限・やめる基準つき)
argument-hint: <ideas/ のファイル名>
---
対象: $ARGUMENTS

1. 対象の idea を読む
2. `templates/experiment.md` の形で `experiments/<アイデア名>.md` を作る
   - 2週間で結果が出る、一番小さい形にする(作り込まない)
   - 予算の上限と時間の上限を必ず入れる。分からなければ予算1万円・週5時間を初期値にしてオーナーに確認する
   - 見る数字は2〜3個、合格ラインは数字で
   - やめる基準を必ず書く
3. 1日目にやることを、作業レベル(30分単位)で3つ出す
4. Claude Code で作れるもの(ツール・テンプレート・販売ページの下書き)があれば、それも挙げて「作りますか?」と聞く
