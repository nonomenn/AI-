---
description: 集めた情報(note)から、別角度の収益化アイデアを6つの型で出して評価する
argument-hint: <notes/ のファイル名、または空欄で直近のnote>
---
対象: $ARGUMENTS(空なら notes/ の一番新しいファイル)

1. 対象の note と `notes/_profile.md`(あれば)を読む
2. CLAUDE.md の「別角度の考え方」の6つの型それぞれで、アイデアを1〜2個出す
3. すべてを1つの表にする: アイデア / 型 / 誰に何をいくらで / 初期費用 / 週の時間 / 天井(推測) / リスク / 相性
4. 上位2つを選び、`templates/idea.md` の形で `ideas/<アイデア名>.md` に保存する
5. 見送りにしたものも、表に理由を一言残す
6. オーナーへの返事: 表と、上位2つを選んだ理由。`/experiment` で検証計画を作るかの一言
