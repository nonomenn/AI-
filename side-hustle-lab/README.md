# 副業リサーチラボ

Xなどで見つけた副業・収益化の情報を集めて、本当か・自分にできるか・別の角度で稼げないかを検討し、
小さく試して記録する Claude Code のプロジェクト。ルールは `CLAUDE.md`。

## 使い方
このフォルダを開いて Claude Code を起動し、次のコマンドを使う。

| コマンド | 使う場面 |
|---|---|
| `/collect <ポストのURL>` | 気になるポストを見つけたら。本文やスクショを貼ってもよい |
| `/angles` | 集めた情報から、別角度の稼ぎ方を考える |
| `/ideas` | 何を試すか迷ったら。候補をランキング |
| `/experiment <アイデア>` | 試すと決めたら。2週間の計画を作る |
| `/log <実験> <内容>` | やったこと・数字を記録 |
| `/digest` | 週に1回のまとめ |

## フォルダ
```
notes/        集めた情報の要約と評価(1件1ファイル)
ideas/        別角度のアイデア
experiments/  実践の計画と記録
digests/      週のまとめ
inbox/        取ってきた原文(Git に入れない)
templates/    各ファイルのひな形
```

## X の情報の集め方
- 自動で一括収集はしない(X の規約上、スクレイピングは不可)。気になったポストのURLを `/collect` に渡す
- たくさん集めたくなったら、X の公式APIキーを用意すれば検索で集める機能を足せる(有料プラン)
